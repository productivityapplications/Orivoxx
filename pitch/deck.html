02 · The solution

One pipeline · three guarantees

Benchmark. Attribute. Prove.

01 · Benchmark

Real tasks, real tests.

A pinned GitHub issue, a base commit, and one hidden test command. The agent runs in Docker; the test runs in the same sandbox. Primary success is exit 0.

02 · Attribute

20 cells. 17 rules.

Every failure maps to a layer × mode cell using trace evidence. No guessed root cause, no model in the attribution path.

03 · Prove

A counterfactual replay.

Reconstruct the workspace, apply the intercepted action, reinstall dependencies, and re-run the real test. The diagnosis is only as good as the proof.

the result

“The attribution says harness × recovery. The replay takes the run from 0.0 to 100.0 — on the real test command.”

No model call enters the replay. The scoring engine never executes produced code.

05 · Architecture

One boundary between measurement and execution

Public product. Private sandbox.

01 · client

Browser

Dark-first Next.js App Router. Task catalogue, result explorer, attribution, replay.

→
02 · edge

Vercel

Read APIs, leaderboard, community submissions, rate limits, origin checks, operator kill switch.

→
03 · store

Upstash

Immutable scorecards, traces, proofs, task queue, validation events, rate counters.

→
04 · runner

VPS runner

Organizer-executed jobs. Clone on host, then hand the bounded workspace to Docker.

→
05 · execution

Docker sandbox

Non-root, read-only rootfs, tmpfs, quotas, no platform secrets, allowlisted proxy.

score path

Static only. The scoring engine never runs produced code, tests, builds, or package installs. A test proves the import graph contains no provider or adapter module.

execution path

Only packages/harness launches agent processes, and only through the Docker executor. The test command runs inside the sandbox.

proof path

Replay reconstructs the workspace, applies the recorded action, reinstalls declared dependencies, and re-runs the real test. No model call.
