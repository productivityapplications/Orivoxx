# Orivoxx pitch deck

Seven-slide HackCulture submission deck, rendered from `pitch/deck.html` with Playwright.

```bash
node pitch/render.mjs
```

Output: `pitch/Orivoxx_Deck.pdf` — 7 pages, 16:9 (13.333 × 7.5 in), dark Coderia palette, Instrument Serif headings, Geist body, #17CF97 accent.

The deck covers: title, problem, solution, real agents/tasks, the 5×4 attribution taxonomy, architecture, and the live demo/proof.
